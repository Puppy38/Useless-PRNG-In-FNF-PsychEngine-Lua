# How To Use:
## [Version without exclusions:](https://github.com/Puppy38/Useless-PRNG-In-FNF-PsychEngine-Lua/blob/main/random%20number%20generator.lua)
Just write `rand(minimum, maximum)`
## [Version with exclusions:](https://github.com/Puppy38/Useless-PRNG-In-FNF-PsychEngine-Lua/blob/main/random%20number%20generator%20with%20exclusions.lua)
Write `rand(minimum, maximum, {exclusion1, exclusion2...})`
**(You can add as many exclusions as you want)**
